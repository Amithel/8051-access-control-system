# 8051 Microcontroller Password-Based Access Control System

An embedded system implementation of a password-authenticated access control unit built with an 8051 microcontroller, simulated in Proteus 8 and compiled using Keil uVision.

## System Overview
- **Microcontroller:** 8051 (AT89C51/AT89S52)
- **Key Features:** Password validation logic, status outputs, and peripheral simulation.
- **Simulation:** Complete hardware layout designed in Proteus 8 using the compiled `.hex` binary.

## Repository Contents
- `audit.c` - Core embedded C source code.
- `audit.hex` - Compiled machine code for microcontroller flashing/simulation.
- `audit.pdsprj` - Proteus 8 Professional simulation schematic.
- `audit.uvproj` - Keil uVision project configuration.

## Software Tools
- Keil uVision IDE
- Proteus 8 Professional Simulation Suite
